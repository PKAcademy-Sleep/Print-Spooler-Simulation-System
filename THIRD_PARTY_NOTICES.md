# Third-party design sources

The Spooler Lab interface adapts the **Simple Light** template by Cruip:

- Repository: https://github.com/cruip/tailwind-landing-page-template
- Upstream commit: `909e38e3249ac575017864a202188b48ef016c9c`
- Copyright notice in upstream README: Copyright 2024 Cruip.
- Upstream license statement: Released under the GPL (the README does not specify a GPL version).

Adapted materials include the floating header and hero layout patterns, button/form utility styles, typography tokens, and `public/images/stripes.svg`. The template's Next.js/React layout patterns are adapted to this project's static HTML and Tailwind CSS; this project does not include the template's marketing copy, login/signup routes, testimonials or sample product assets.

The upstream README permits personal and commercial project use, asks users not to republish, redistribute or resell the template itself, and states that attribution is optional. The source repository and its license statement are retained here for reference.

Spooler Lab's simulation logic, Thai explanations and original C source are project content, separate from the template's design materials.
